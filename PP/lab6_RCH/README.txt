Лабораторная работа 10 по паттерну Chain of Responsibility.

Состав архива:
- IRC — библиотека интерфейсов (IRC.dll)
- RC — библиотека реализации (RC.dll)
- DP10RCh_test — консольное приложение для тестирования

Что сделано:
1. Воспроизведен пример из лекции 6 (п.9) по изображениям.
2. В Context добавлен собственный метод max(), который увеличивает Z на max(X, Y).
3. В отдельном расширенном тесте добавлен элемент цепочки, выполняющий max() на прямом и обратном проходе.
4. Добавлена трассировка выполнения для проверки работы нового элемента.

Сборка:
1. Открыть решение/проекты в Visual Studio или выполнить в терминале:
   dotnet build
2. Запуск теста:
   dotnet run --project DP10RCh_test
