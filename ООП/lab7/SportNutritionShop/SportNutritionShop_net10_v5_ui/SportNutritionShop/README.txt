Запуск проекта:
1. Откройте SportNutritionShop.csproj в Visual Studio 2022.
2. Нужен .NET 10 SDK и workload Desktop development with .NET.
3. Нажмите F5.

Аккаунты:
admin / 123
client / 123

Функции:
- 2 роли
- поиск, фильтры, сортировка
- рабочая корзина
- оформление заказа
- добавление/удаление/редактирование товаров
- сохранение в JSON
- локализация RU/EN
- собственная иконка и курсор
