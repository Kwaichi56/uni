# Лабораторная работа 10 — Repository и Unit of Work

Проект продолжает лабораторную работу 9: WPF-магазин спортивного питания, EF Core Code First и SQLite. Целевая платформа — .NET 10.0 Windows.

## Запуск

Откройте `SportNutritionShop.slnx` в Visual Studio с .NET 10 либо выполните `dotnet build SportNutritionShop.slnx`. Запустите `SportNutritionShop`. При первом запуске база создаётся в `SportNutritionShop/bin/Debug/net10.0-windows/Data/SportNutritionShop.db`. Учебные учётные записи: `admin / 123` и `client / 123`.

## Реализация задания

`Data/IShopUnitOfWork.cs` задаёт контракты репозиториев и единицы работы. `Data/EfRepositories.cs` содержит общий CRUD-репозиторий, а также репозитории товаров и категорий с запросами поиска, остатков и статистики. `Data/EfShopUnitOfWork.cs` создаёт **один** `ShopDbContext` для всех репозиториев в рамках операции, сохраняет изменения и управляет транзакцией. Это позволяет, например, оформить заказ и уменьшить остатки одним атомарным действием.

`Services/DatabaseService.cs` выполняет бизнес-операции и преобразование сущностей в модели интерфейса. Он работает через интерфейс `IShopUnitOfWork`, без прямых вызовов EF Core. При ошибке до `CommitAsync` транзакция откатывается при освобождении. Для каждой операции создаётся отдельная единица работы; контекст не разделяется между окнами приложения.

Существующие функции 9-й работы — каталог, корзина, профиль, авторизация, административный CRUD, LINQ-поиск, сортировка, низкий остаток, статистика и журнал изменений — сохранены. Подробные ответы на вопросы задания находятся в `Answers_Lab10.md`.

Пароли `123` унаследованы от учебного проекта и не подходят для реального применения.

Проверку репозиториев, отката транзакции и оформления заказа можно запустить командой `dotnet run --project Verification/Verification.csproj`.
