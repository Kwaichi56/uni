# Лабораторная работа 9 — Entity Framework

Проект продолжает лабораторную работу 8 о магазине спортивного питания. WPF-интерфейс,
каталог, корзина, роли и окно администратора сохранены; работа с сущностями переведена
с ручных ADO.NET-запросов на EF Core. Решение `SportNutritionShop.slnx` рассчитано
на .NET 10.0 Windows.

## Запуск

1. Открыть `SportNutritionShop.slnx` в Visual Studio с поддержкой .NET 10 или выполнить
   `dotnet build SportNutritionShop.slnx`.
2. Запустить проект `SportNutritionShop`. При первом запуске EF Core создаст SQLite-базу
   рядом с приложением: `SportNutritionShop/bin/Debug/net10.0-windows/Data/SportNutritionShop.db`.
3. Войти как `admin / 123` для доступа к окну БД либо как `client / 123`.

## Соответствие условию

| Требование | Реализация |
| --- | --- |
| EF через NuGet | `Microsoft.EntityFrameworkCore.Sqlite 8.0.4` в `SportNutritionShop.csproj` |
| Конфигурационный файл | `App.config`: строка подключения, лимит остатка, таймаут |
| Code First | `Data/ShopEntities.cs`, `Data/ShopDbContext.cs`, `EnsureCreatedAsync` |
| Связи | Категория → товары; пользователь → заказы; заказ → позиции; товар → позиции |
| CRUD | `Services/DatabaseService.cs`: товары, категории, пользователи, профиль и заказы |
| Сортировка, фильтрация, поиск | `SearchProductsAsync`: LINQ to Entities, `Where`, `Like`, `OrderBy`; поле поиска и список критерия в окне БД |
| Асинхронность | `ToListAsync`, `SaveChangesAsync`, `EnsureCreatedAsync` и асинхронные команды окна |
| Транзакции | Сохранение таблицы, группы товаров и оформление заказа через `BeginTransactionAsync` |
| Генерация схемы из модели | SQL-сценарий `ModelGeneration/CodeFirstSchema.sql`, полученный из модели EF Core |
| Database First и Model First | Пошаговая демонстрация в `MODEL_GENERATION.md` |

Сущности БД отделены от моделей интерфейса. Это позволяет не сохранять вычисляемые
свойства WPF-моделей. Схема строится из классов и Fluent API, включая внешние ключи
и правила удаления. В `Products.ImageData` хранятся изображения; триггеры SQLite
пополняют `AuditLog` при изменениях товаров.

В окне БД одно поле поиска и список «Поле». Режим «Все поля» ищет по краткому и
полному названию, бренду и категории; остальные режимы ограничивают поиск одним
полем. Кнопки сортировки для
товаров выполняют запрос на стороне БД по цене. Для редактирования после просмотра
результатов нужно нажать «Обновить».

Пароли `123` оставлены из предыдущей учебной работы; приложение не предназначено
для использования с реальными учётными записями.
