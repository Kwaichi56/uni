Лабораторная работа № 8
Создание WPF-приложения управления базой данных на ADO.NET

ЗАПУСК
1. Откройте SportNutritionShop.sln или SportNutritionShop.csproj в Visual Studio 2026.
2. Убедитесь, что установлен .NET 10 SDK и компонент Desktop development with .NET.
3. Восстановите NuGet-пакеты и нажмите F5.

Учетные записи:
admin / 123 — администратор, доступно окно «База данных»;
client / 123 — клиент магазина.

БАЗА ДАННЫХ
СУБД: SQLite.
Провайдер ADO.NET: Microsoft.Data.Sqlite 10.0.10.
Строка подключения и параметры находятся в App.config.
Рабочий файл создается автоматически по пути:
bin\Debug\net10.0-windows\Data\SportNutritionShop.db

Если файла БД нет, приложение при запуске выполняет Data\Schema.sql, создает
таблицы, связи, представление и триггеры, затем добавляет начальные записи.

СТРУКТУРА
- Categories — категории товаров;
- Products — товары; поле ImageData имеет тип BLOB и хранит изображение;
- Users — учетные записи и профили;
- Orders — заказы;
- OrderItems — позиции заказов;
- AuditLog — журнал изменений товаров, заполняемый триггерами;
- StoredCommands — именованные SQL-команды.

Связи:
Categories 1:M Products;
Users 1:M Orders;
Orders 1:M OrderItems;
Products 1:M OrderItems.

СООТВЕТСТВИЕ ЗАДАНИЮ
- просмотр, добавление, редактирование и удаление записей;
- DataGrid с привязкой данных и кнопками перехода между таблицами;
- сортировка по столбцам и отдельные кнопки сортировки;
- обычные и параметризованные запросы;
- асинхронная загрузка таблиц, отчета по остаткам и статистики;
- транзакции при сохранении CRUD-изменений, профиля, товаров и заказа;
- автоматическое создание БД;
- строка подключения в App.config;
- графические данные в Products.ImageData (BLOB);
- представление vw_ProductCatalog;
- триггеры trg_Products_Insert, trg_Products_Update, trg_Products_Delete.

ОСОБЕННОСТЬ SQLITE И ХРАНИМЫХ ПРОЦЕДУР
SQLite не поддерживает нативные хранимые процедуры. Поэтому пункт задания
реализован совместимым с SQLite способом: SQL хранится в таблице StoredCommands,
выбирается по имени параметризованным запросом и выполняется через ADO.NET.
Кнопка sp_ProductStatistics в окне администратора демонстрирует этот механизм.
Команда sp_OrdersByUser демонстрирует именованную команду с параметром @login.

ОСНОВНЫЕ ФУНКЦИИ ПРИЛОЖЕНИЯ
- каталог, поиск, фильтры и сортировка;
- корзина и оформление заказа в одной транзакции;
- административное редактирование товаров;
- отдельное окно управления таблицами БД;
- роли администратора и клиента;
- профили пользователей в БД;
- темы, локализация RU/EN, пользовательские элементы управления, Undo/Redo.

Примечание: пароли хранятся открытым текстом только для учебной демонстрации.
В производственном приложении необходимо хранить стойкие хеши паролей.
