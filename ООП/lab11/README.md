# Лабораторная работа 11 — MVVM в WPF

Продолжение проекта магазина спортивного питания из лабораторной работы 10. Каталог, корзина, профиль, вход и администрирование базы данных организованы по схеме Model–View–ViewModel.

## Запуск

Откройте `SportNutritionShop.slnx` в Visual Studio с .NET 10 или выполните `dotnet build SportNutritionShop/SportNutritionShop.csproj` и запустите приложение. Учебные учётные записи: `admin / 123` и `client / 123`. База SQLite создаётся при первом запуске.

## Что реализовано

- **Model:** `Models/` и `Data/` содержат данные, сущности EF Core, репозитории и Unit of Work; `Services/` выполняет операции с данными.
- **ViewModel:** `MainViewModel`, `LoginViewModel`, `ProfileViewModel`, `DatabaseAdminViewModel` предоставляют состояние, `ICommand` и уведомления `INotifyPropertyChanged`. Для коллекций используется `ObservableCollection`.
- **View:** окна XAML показывают данные через `Binding` и вызывают команды. В code-behind остались действия, связанные только с WPF: открытие окон, чтение `PasswordBox`, настройка столбцов `DataGrid`, фиксация его редактирования и демонстрация маршрутизируемых событий из предыдущей работы.

`SaveCartCommand` доступна только при непустой корзине. Выбор сохранённой корзины загружает её через свойство ViewModel. В профиле текстовые поля и переключатели языка/темы связаны с ViewModel двусторонними привязками.

Ответы на контрольные вопросы находятся в `Answers_Lab11.md`. Дополнительное задание про игровые объекты обозначено в методичке как необязательное и не входит в магазин.
